操作・使いやすさについて
Q
スマホやパソコンが苦手なドライバーでも使えますか？
✔ 使えます
ドライバーが操作するのは「ボタンを押すだけ」です。次に押すべきボタンが色で分かるよう設計されているため、「黄色を押して」「緑になったら完了」と色だけで説明できます。文字入力はほとんどありません。スマホ操作に不慣れな方でも導入当日から使いこなせます。
Q
管理者はパソコンが必要ですか？スマホだけでもできますか？
✔ スマホでもできます
スプレッドシートはPCでもスマホのブラウザからでもアクセスできます。外出先からでも運行状況の確認は可能ですが、集計・請求書生成などの詳細操作はPCの方が快適です。
Q
操作マニュアルはありますか？研修は必要ですか？
✔ マニュアルはシステム内に内蔵
スプレッドシート内に「使い方シート」が組み込まれているため、別途マニュアルを探す必要はありません。ドライバーへの説明はアプリの色だけで完結するため、研修は基本的に不要です。分からないことはLINEでサポートを受けられます。
導入・セットアップについて
Q
導入にどれくらい時間がかかりますか？
✔ 最短で当日から使えます
LINEで申し込みいただいた後、初期設定（会社情報・乗務員登録・マスタ設定）を完了すれば使い始められます。設定時間の目安は30〜60分程度です。打合せや訪問は一切不要です。
Q
既存のExcelデータを引き継ぐことはできますか？
△ 一部対応
運行データのCSV取込機能があります。ただし、過去の全データを完全移行することは想定していません。新規でスタートして、過去データは既存のExcelを参照する形が最も運用しやすいです。導入後は全て自動でデータが蓄積されます。
Q
Googleアカウントは必要ですか？
✔ 管理者はGoogleアカウントが必要（ドライバーは不要）
管理者（スプレッドシートを使う方）はGoogleアカウントが必要です。ドライバーはGoogleアカウント不要です。スマホのブラウザ（Chrome/Safari）だけで動作します。アプリのインストールも不要です。
セキュリティ・データについて
Q
データのセキュリティは大丈夫ですか？情報が漏れませんか？
✔ Googleのセキュリティで保護
データはGoogleスプレッドシート（Google Drive）に保管されます。Googleの企業向けセキュリティ基準が適用されており、アクセス権を持たない第三者はデータを見ることができません。また、シートには保護設定が施されており、誤操作によるデータ破損も防止しています。
Q
サーバーが落ちてデータが消えることはありませんか？
✔ 自動バックアップで保護
Googleのクラウド上に保管されるため、PCやスマホが壊れてもデータは消えません。またシステム内に自動バックアップ機能が組み込まれており、万が一のシート誤削除時も1〜3秒で自動復元されます。
Q
解約したらデータはどうなりますか？
✔ データはそのまま手元に残ります
データはGoogleスプレッドシートに保存されているため、解約後もスプレッドシートはそのままお手元に残ります。データを失うことはありません。システムの機能（自動化など）が停止するだけで、蓄積されたデータはずっと参照できます。
料金・サポートについて
Q
乗務員が増えた場合、追加費用はかかりますか？
✔ 追加費用なし
登録できる乗務員数に上限はありません。乗務員が増えても料金は変わりません。マスタシートに追加するだけで、すぐに使い始められます。
Q
サポートはどのように受けられますか？
✔ LINEでいつでも相談できます
サポートはLINEで受け付けています。よくある質問は自動で返信されます。それ以外の問い合わせにも対応しています。電話やメールではなくLINEで完結するため、気軽に相談できます。
Q
無料でお試しできますか？途中で解約できますか？
✔ 無料でお試しできます
まずは無料でお試しいただけます。実際に使ってみてから契約をご判断いただけます。無理な勧誘は一切ありません。解約はLINEまたはメールで連絡いただければすぐに対応します。
Q
Excelと何が違うのですか？Excelでよくないですか？
✔ 「自動化」と「リアルタイム性」が根本的に違います
Excelは人が手で入力・管理する必要があります。本システムはドライバーがアプリを操作した瞬間にデータが自動反映されます。また損益の自動計算・監査書類の自動生成・バックアップ・排他制御など、Excelでは実現できない業務自動化が全て組み込まれています。「Excelをさらに賢く自動化したもの」と考えてください。
